# Resumo

SDK client para acesso à API da Kobana em python

## Contexto

A Kobana é uma plataforma de automação financeira.

Mais sobre a Kobana aqui: https://ai.kobana.com.br

A referência da API em swagger está aqui: https://raw.githubusercontent.com/universokobana/kobana-api-specs/refs/heads/main/swagger/all-versions/kobana-api-all-versions-openapi-3_1.json

A Kobana possui uma biblioteca SDK em Ruby que o fonte está aqui: https://github.com/universokobana/kobana-ruby-client

A Kobana possui uma biblioteca SDK em Node.js que o fonte está aqui: https://github.com/universokobana/kobana-nodejs-client

A Kobana possui uma biblioteca SDK em Python que o fonte está aqui: https://github.com/universokobana/kobana-python-client

# Instruções

Baseado na documentação da API e na assinatura do código do SDK em Ruby, Node.js e Python, planeje o desenvolvimento do código de uma bilbioteca em PHP.

Considere usar as bilbiotecas Guzzle, PHPUnit, php-vcr e vlucas/phpdotenv.

Grave o planejamento em arquivos .md na pasta docs.

Depois de ter o planejamento pronto, faça a implementação do código, com testes unitários e gravação dos requests realizados.

Garanta que nenhum token será gravado em arquivos no respositorio.

Não crie branches, trabalhe na main.

Pode ir fazendo commits conforme for realizando o trabalho.

Todo o código fonte deve ser escrito em inglês.
